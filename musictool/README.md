# 함현고등학교 교가 · 노래방 가사 학습

교가 음원 싱크에 맞춰 가사가 노래방 스타일로 하이라이트되는 웹 페이지입니다.
고등학교 1학년 교가 가사 학습용.

## 파일 구성

```
index.html              메인 페이지 (전체 코드 포함)
assets/school-song.mp3  교가 음원(AR)
assets/background.jpg   배경 이미지
```

## 기능

- 전주 동안 제목 화면 → 첫 소절 3초 전 3·2·1·시작! 카운트다운 → 가사 화면 전환
- 어절 단위 탭싱크 + 악보 리듬(음표 길이) 기반 음절별 하이라이트
- 한 곡 반복, 재생 속도(0.7×/0.85×/1.0×), 음정 키 조절(♭/♯ 반음 단위 ±5)
- 이전/다음 소절 이동(구간 반복 연습), 스페이스바 재생/일시정지
- 싱크 조정 모드: 어절별 탭싱크 재기록 → 타이밍 코드 복사/적용

## GitHub Pages로 배포하기

1. GitHub에서 새 저장소 만들기 (Public)
2. `index.html`과 `assets` 폴더를 그대로 업로드
   (Add file → Upload files → 끌어다 놓기 → Commit changes)
3. 저장소 **Settings → Pages**
4. Source: `Deploy from a branch`, Branch: `main` / `(root)` → Save
5. 1~2분 뒤 `https://아이디.github.io/저장소이름/` 으로 접속

수업 시간에는 이 주소만 열면 되고, 학생들에게 링크로 공유할 수 있습니다.

## 타이밍 수정

싱크가 어긋나면 페이지의 **[🎯 싱크 조정]**으로 어절별 타이밍을 다시 찍은 뒤,
복사한 코드를 `index.html`의 `let T = [...]` 배열과 교체하면 됩니다.
