# [음악수업자료]

일반계 고등학교 음악 수업 자료 모음입니다.
2022 개정 교육과정 기준으로 제작했습니다.

## 구성

| 폴더 | 내용 |
|---|---|
| `1학년/` | 음악 감상 및 활동 자료 |
| `3학년/` | 진로 연계 음악 자료 |
| `논술/` | 논술 수업 자료 |
| `공용/` | 학습지 양식, 평가 루브릭 |

## 사용 안내

- 파일은 `[학년]_[단원]_[자료명]` 형식으로 이름을 붙였습니다.
- 수정한 자료는 커밋 메시지에 변경 내용을 적어 주세요.

## 라이선스

수업 목적의 자유로운 사용·수정이 가능합니다.
출처 표시 후 공유해 주세요.
