# 멀티모드 튜너 (Multi-Mode Tuner)

고등학교 음악 수업에서 **악기 조율 원리**를 시각적으로 익히기 위한 웹 기반 튜너 시뮬레이터입니다.
학생들이 실제 악기를 조율하기 전에, 화면에서 줄 번호를 확인하고 줄감개를 돌려보며 튜너 바늘이 어떻게 반응하는지 체험할 수 있습니다.

> 별도 설치 없이 `index.html` 파일 하나만 열면 동작합니다. 인터넷 연결도 필요하지 않습니다.

## 주요 기능

### 5가지 모드
| 모드 | 악기 | 조율 |
|---|---|---|
| **C** | 반음계(Chromatic) | 피아노 건반으로 음이름 확인 |
| **G** | 기타 | E A D G B E (6줄) |
| **B** | 베이스 | E A D G (4줄) |
| **V** | 바이올린 | G D A E (4줄) |
| **U** | 우쿨렐레 | G C E A (High-G / Low-G 선택) |

### 현악기 모드
- 실제 악기를 참고한 **헤드 모양**과 **줄감개 배치**
- 줄감개를 **마우스·손가락으로 끌어서** 조율 (위로 끌면 음↑, 아래로 끌면 음↓)
- 줄을 클릭하면 **현재 음정 그대로 소리**가 남 (Karplus-Strong 합성)
- 각 줄의 **번호와 음이름**을 지판에 표시
- 조율 방향(시계/반시계) 안내

### 반음계 모드
- **도~도 한 옥타브** 피아노 건반
- 건반을 누르면 해당 음으로 즉시 이동하며 **피아노 음색**으로 재생
- 화살표 포인터가 현재 음의 건반을 가리킴

### 튜너 화면 (클립온 튜너 재현)
- 평소에는 **파란색 LCD**, 음이 정확히 맞으면 **초록색**으로 전환
- 바늘 미터(−50 ~ +50 cents), 음이름, 줄번호, 모드 표시
- 음이 낮으면 ◀, 높으면 ▶ 화살표 점등

### 수업 운영 도구
- 🎲 **흐트러뜨려 연습** — 음정을 무작위로 어긋나게 하여 반복 연습
- ✅ **한 번에 맞추기** — 정답 상태를 즉시 보여주기
- 키보드 지원: `↑`/`↓` 조율, `←`/`→` 줄 선택, `Space` 튕기기

## 사용 방법

### 1) 그냥 파일로 사용
`index.html`을 내려받아 브라우저로 열면 끝입니다. (수업용 노트북·태블릿에 복사해 두고 오프라인 사용 가능)

### 2) GitHub Pages로 배포
1. 이 저장소를 fork 하거나 새 저장소에 파일을 업로드합니다.
2. 저장소 **Settings → Pages** 로 이동합니다.
3. **Source**를 `Deploy from a branch`, **Branch**를 `main` / `(root)`로 설정하고 저장합니다.
4. 1~2분 뒤 `https://<사용자이름>.github.io/<저장소이름>/` 에서 접속할 수 있습니다.

### 3) 로컬 서버로 실행 (선택)
```bash
git clone https://github.com/<사용자이름>/<저장소이름>.git
cd <저장소이름>
python3 -m http.server 8000
# 브라우저에서 http://localhost:8000 접속
```

## 수업 활용 예시

1. **조율 원리 도입** — "조이면 음이 올라가고, 풀면 내려간다"를 줄감개를 직접 끌어보며 확인
2. **줄 번호 익히기** — 우쿨렐레 4·3·2·1번 줄과 G·C·E·A의 대응 관계 확인
3. **튜너 읽는 법** — 바늘이 왼쪽이면 낮음(조이기), 오른쪽이면 높음(풀기)
4. **모둠 활동** — 🎲 버튼으로 무작위 상태를 만든 뒤 누가 빨리 4줄을 다 맞추는지 겨루기
5. **실물 악기 연결** — 화면으로 연습한 뒤 실제 우쿨렐레와 클립온 튜너로 이어서 실습

## 기술 정보

- **의존성 없음** — 순수 HTML + CSS + JavaScript 단일 파일 (외부 라이브러리·CDN·빌드 도구 불필요)
- **그래픽** — 인라인 SVG로 헤드·줄감개·LCD·피아노 건반을 직접 그림
- **소리** — Web Audio API
  - 현악기: Karplus-Strong 알고리즘으로 발현음 합성
  - 피아노: 배음을 더한 오실레이터 합성
- **접근성** — 키보드 조작 지원, `prefers-reduced-motion` 존중
- **브라우저** — Chrome, Edge, Safari, Firefox 최신 버전 (모바일·태블릿 터치 지원)

> ⚠️ 브라우저 정책상 **첫 클릭·터치 이후에 소리가 활성화**됩니다. 소리가 안 나면 화면을 한 번 클릭해 보세요.

## 알려진 제한 사항

- 마이크로 실제 소리를 감지하는 기능은 없습니다. **조율 원리를 익히는 시뮬레이터**입니다.
- 줄감개 회전 방향(시계/반시계)은 일반적인 기어드 튜너 기준입니다. 실물 악기는 줄이 감긴 방향에 따라 반대일 수 있으므로, 수업 전에 보유 악기를 확인해 안내해 주세요.
- 헤드 모양과 줄감개 배치는 교육용으로 단순화한 그림입니다.

## 커스터마이징

`index.html` 안에서 직접 수정할 수 있습니다.

| 항목 | 위치 |
|---|---|
| 조율 주파수 | 상단 `const F = { ... }` |
| 모드별 줄 구성 | `const FREQ_OF = { ... }` |
| 헤드 모양·줄감개 좌표 | `const LAYOUT = { ... }` |
| 허용 오차(cents) | `const OK = 5` |
| ▲▼ 한 번의 변화량 | `const STEP = 4.2` |
| 색상 테마 | `<style>` 상단의 `:root` 변수 |

## 여러 자료를 함께 운영하기 (링크 모음 페이지)

`hub.html`은 수업 자료 링크를 모아 두는 첫 화면입니다. 교가·튜너 등 자료가 늘어날 때 사용하세요.

### 권장 폴더 구조
```
저장소/
├── index.html      ← hub.html 의 내용 (링크 모음 첫 화면)
├── song/
│   └── index.html  ← 교가
└── uke/
    └── index.html  ← 멀티모드 튜너
```

### 접속 주소
| 자료 | 주소 |
|---|---|
| 링크 모음 | `https://아이디.github.io/저장소이름/` |
| 교가 | `https://아이디.github.io/저장소이름/song/` |
| 튜너 | `https://아이디.github.io/저장소이름/uke/` |

### 자료 추가 방법
`hub.html`(또는 `index.html`) 맨 아래 `<script>` 안의 `ITEMS` 목록에 항목을 추가하면 카드가 자동으로 생깁니다.

```javascript
{
  title: "리코더 운지법",
  desc:  "손가락 위치를 눌러서 확인",
  url:   "recorder/",
  tag:   "기악",
  icon:  "🎼"
},
```

`tag`를 새로 쓰면 상단 필터 버튼도 자동으로 만들어집니다. (자료가 하나뿐일 때는 필터가 숨겨집니다.)
